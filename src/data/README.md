# Campus SnackPass

Campus SnackPass is a college canteen food ordering web application built using React and Vite.

(Add your Vercel link here)

## Technologies Used

- React.js
- Vite
- JavaScript
- CSS

## Features

- View food menu
- Search food items
- Filter by category
- Add items to cart
- Manage cart items
- Calculate total price

## Project Structure

- Components: Reusable React components
- Assets: Food images
- Data: Menu data

ChatGPT was used as a development assistant for understanding concepts, debugging errors, and code suggestions during development.
